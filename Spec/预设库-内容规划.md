## 2. 语义表的内容规则（如何把"乱配/漏配"收敛为精确适配）

**核心原则：一条 `<Link Target="目标" Facility="设施"/>` = 一条经过人工/半人工确认的语义连接。**
不做"类别内 × 全开"，只做「原版与 VFE 都没有 patch 到的第三方目标」的定向补连。

### 2.1 生产目标按 VFE 柜子类别归属（用户确认的分类思路）

VFE Production 提供的链接设施组天然对应生产类型（见 [Buildings_Linkables.xml](file:///e:/steam/steamapps/workshop/content/294100/1880253632/1.6/Defs/Buildings_Linkables.xml)）：

| VFE 设施 | 服务目标类型 | 第三方目标分型依据 |
|---|---|---|
| `VFE_KitchenSinkCabinet` | 烹饪/屠宰台 | 有烹饪/屠宰相关 Recipe |
| `VFE_TailorCabinet` | 裁缝台 | 产服装 |
| `VFE_SmithyCabinet` | 锻造台 | 产武器/工具/金属加工 |
| `VFE_MachiningCabinet` | 机械加工台 | 产零部件/机械 |
| `VFE_DrugCabinet` | 药品台 | 产药品 |
| `VFE_FabricationCabinet` | 制造台 | 高级装配 |
| （Medical Module 各类医疗附属） | 医疗床/医疗台 | `canLinkToMedBedsOnly` / 医疗 Recipe |

> 即：给种族工作台做语义表时，先按「该目标实际能产什么/服务于什么」归类到上表某列，再只写入该列的柜子，另补 `ToolCabinet`（原版通用工具柜，几乎所有工作台都该有）。

### 2.2 床类分型（粗制 / 家用 / 医疗）

| 分型 | 语义表策略 |
|---|---|
| 医疗床 | 只接收 VFE Medical 的医疗附属（引擎 `canLinkToMedBedsOnly` 也自动限制） |
| 家用床 | 床头柜/梳妆台/雕像位等舒适类设施 |
| 粗制床 | 通常不补（成本与收益不成比例），除非风格 mod 特意提供 |

### 2.3 导出内容语义（决策：全部启用）
按来源导出 = 该种族目标**当前全部启用**连接（**含原始已声明行**，如鼠族工作台 → `ToolCabinet`）。
语义表自包含「该目标应该连什么」的完整声明：版本差异导致目标 XML 丢失原始声明时导入仍能补全，最鲁棒。
注：手工编写语义表时才无需重复写原始已声明的行（仅补「缺的」，如 `VFE_TailorCabinet`）。

## 3. 预设包清单（手动导入）

**包组织规则**：按**目标来源（种族）**划分，一个种族一包；包内目标全部来自该种族，设施可来自任意已安装的设施 mod（VFE / Rimkea / 仙路…），跨源自由配对。多包导入 = union，可叠加。

| 预设包 | 文件 | 内容（语义表） |
|---|---|---|
| P1 鼠族整合 | `FC_Recommended_Ratkin.xml` | 鼠族生产目标 ← ToolCabinet(若缺)+VFE 对应柜；鼠族医疗/床目标 ← VFE Medical |
| P2 绮罗整合 | `FC_Recommended_Kiiro.xml` | 同上结构 |
| P3 米莉拉整合 | `FC_Recommended_Milira.xml` | 同上结构 |
| P4 萌螈整合 | `FC_Recommended_Amby.xml` | 同上结构 |
| P5 通用补全 | `FC_Recommended_Generic.xml` | 原版床/通用目标 ← VFE/Rimkea 常用设施；机制冒烟包 |

## 4. 内容生产流程

**避免凭记忆写 defName**；直接在游戏内配置后按来源导出（UI 已支持）：

1. **装 mod**：把目标 mod 放入本地 Mods（已装鼠族、VFE Production/Medical/Spacer/Framework）；
2. **游戏内配置**：打开设置矩阵，对某个种族目标的每个工作台，点开其应连接的设施（如鼠族缝纫台 → 工具柜 + 缝纫柜）；`ResetToOriginal` 后默认仅原始链接，只需补「缺的」；
3. **按来源导出**：全局操作 → 导出 → 选该种族 mod 来源 → 输入 `FC_Recommended_<种族>` → 生成 v2 `<Link>` 语义表到 `Presets/`；
4. **游戏内实测**（P2/P3/P4 用例）：放缝纫柜/医疗床蓝图 → 出现连线 → 建成连接 → 拆除重装正常；
5. **入库**：随发行。
